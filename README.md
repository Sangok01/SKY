# 하늘섬 카드 원정대

초등 5~6학년용 **덱빌딩 카드 모험 게임**입니다. 학습 내용은 없는 순수 게임이고, 전략적으로 생각하기·계획 세우기·위험 판단을 연습할 수 있습니다.

## 바로 해 보기
- `index.html`을 더블클릭하거나, GitHub Pages에 올린 주소로 접속하면 **혼자 하기**로 바로 플레이할 수 있어요.
- 소리(BGM·효과음)는 기본으로 켜져 있어요. 브라우저 규칙상 화면을 한 번 누른 뒤부터 소리가 나요. ⚙️ 설정에서 끌 수 있어요.

## 게임 구성
| 화면 | 내용 |
|---|---|
| 원정대원 4명 | 한결(검의 용사·막기), 나린(자연의 수호자·동물 동료·회복), 세라(마법의 선구자·별빛 모으기), 하진(그림자 닌자·따끔·빠른 카드) |
| 갈림길 지도 | 섬마다 6층 + 보스. ⚔️전투 · 😈강한 적 · 💬만남 · ❓수수께끼 · 🛒상점 · 🔥쉼터 · 🎁보물 · 👑보스 |
| 세 줄 전투 | 에너지 3, 카드 5장. 적 머리 위에 다음 행동이 보여요. 동료 카드를 줄에 놓으면 그 줄의 적과 싸우고 대신 맞아 줘요. 🪽날개 달린 적은 동료를 건너뛰어요 |
| 설득 대결 | 💬만남과 마지막 보스는 싸우는 대신 **말 카드**로 설득할 수 있어요. 상대의 고집을 0으로! 실패하면 싸워야 해요 |
| 덱 만들기 | 이길 때마다 카드 1장 고르기(안 받아도 됨), 쉼터에서 강화, 상점에서 사고·빼기, 유물 19종, 간식 5종 |
| 길이 | 짧은 원정(섬 1개·약 15분) / 긴 원정(섬 3개·약 40분). 쉬움 모드, 긴 원정을 이기면 별 단계(★1~5)가 열려요 |

키보드: 숫자 1~9 카드 고르기 · Enter 쓰기 · Esc 취소 · E 턴 끝. 카드·적·유물 위에 마우스를 올리거나 길게 누르면 설명이 나와요.

## 🏫 학급코드 · 학급 현황판
- **선생님:** 타이틀의 「📊 학급 현황판」 → 수업 이름, 원정 길이(짧은/긴), 비밀번호 → 6자리 수업 코드.
- **학생:** 「🏫 수업 코드로 입장」 → 코드·번호·이름(또는 별명). 다른 기기에서도 같은 정보로 들어오면 기록이 이어져요.
- **현황판에 보이는 것**
  - 학생 현황: 지금 영웅과 섬·층, 진행률, 최고 점수, 승리 여부, 마지막 활동
  - 학생 상세: 도전 횟수, 영웅별 승리, 최고 기록, 지금 덱 장수, 유물
  - 문항 분석: 이 게임에서는 **전투마다 처음 만났을 때 이긴 비율**이 보여요. 낮은 전투는 함께 작전을 이야기해 보기 좋아요.
- **개인정보:** 학생에게는 번호와 이름(또는 별명)만 받아요. 기록은 선생님의 학급 서버에만 저장되고, **수업 코드를 만든 지 3일이 지나면 코드와 기록이 모두 자동으로 지워져요.**

### 학급코드 켜기 (처음 한 번, 약 15분)
GitHub Pages만으로는 학생 기록을 모을 수 없어서 **Cloudflare Workers(무료)** 에 함께 올립니다.
1. Cloudflare → **Storage & Databases → D1** → 데이터베이스 `sky-card-db` 만들기 → 콘솔에 `schema.sql` 붙여 넣고 실행
2. 데이터베이스 ID를 `wrangler.toml`의 `database_id`에 넣기
3. **Workers & Pages → 만들기 → Git 저장소 가져오기**로 이 저장소 연결 → 배포
4. Worker **설정 → 변수와 비밀**에 `SECRET` 추가(아무 긴 문장)
5. 학생들에게 `https://sky-card-expedition.<계정>.workers.dev` 주소를 알려 주기

- GitHub Pages 주소에서도 학급코드를 쓰려면 `index.html`의 `window.CLASS_API = ''`에 위 workers.dev 주소를 넣으세요.
- 보관 기간은 `wrangler.toml`의 `KEEP_DAYS = "3"`으로 바꿀 수 있어요.

## 만든 방법 · 그림 출처
- 캐릭터 초상화·작은 동작 그림·스킬 이펙트·타이틀 그림은 선생님이 주신 키아트와 캐릭터 시트에서 잘라 썼어요. 적·동료 동물·카드 문양·배경은 코드로 그렸어요.
- 게임 방식은 덱빌딩 로그라이크(갈림길 지도·적 행동 미리 보기·세 줄 보드·동료·설득 대결)에서 착안했고, 이름·캐릭터·그림은 모두 새로 만들었어요.

## 테스트 (개발용)
```
node --experimental-sqlite tools/local-server.mjs 8795    # Cloudflare 없이 같은 서버 실행
python3 tools/class_e2e.py http://localhost:8795/ shots  # 선생님 1 + 학생 4명 자동 플레이
```
브라우저 자동 플레이: `index.html#autotest-knight-long-3` (영웅: knight·ranger·mage·rogue, 길이: short·long)
